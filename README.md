Book Lover's Corner
A web page that displays different types of novels (e.g., romance, action, etc.) and allows users to find apps to access these novels, Version 1.0.0
By Margaret Wanjiru
Description
"Book Lover's Corner" is a web page designed for book lovers to explore various types of novels, such as romance, action, and more. Users can easily browse and find apps that offer access to novels. The platform also features a feedback section where users can share their thoughts on novels, including their preferences and what they enjoy about them. The site is simple to use and doesn’t require installation—just access it directly via a browser.

Setup/Installation Requirements
No installation is needed. The site is ready for use by simply browsing.

Users can access apps to read novels directly through the site.

The application works smoothly on all major browsers (Chrome, Firefox, Safari, etc.).
